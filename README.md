# Applications Eurallia Finance Marseille

Pages et mini-applications publiées sur Netlify. Un dossier par application ; chaque dossier contient un `index.html` autonome et correspond à un site Netlify (réglage « Base directory » = nom du dossier).

| Dossier | Contenu | Adresse publique |
|---|---|---|
| `simulateur-valorisation` | Support de formation à la valorisation d'entreprise (10 modules, quiz, simulateur) | à compléter après la mise en ligne |

Règles :

- Aucun document de dossier client dans ce dépôt.
- La version de référence de chaque page reste dans le Dropbox d'équipe ; ce dépôt n'en garde que la version publiée.
- Les mises à jour sont faites par Claude Code : modification, envoi sur GitHub, publication automatique par Netlify.
