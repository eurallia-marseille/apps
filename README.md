# Applications Eurallia Finance Marseille

Pages et mini-applications publiées sur Netlify. Un dossier par application ; chaque dossier correspond à un projet Netlify. Une page statique se règle avec « Publish directory » = nom du dossier ; une application avec fonction (comme `quiz-ipag`) se règle avec « Base directory » = nom du dossier, qui contient son `netlify.toml`.

| Dossier | Contenu | Adresse publique |
|---|---|---|
| `simulateur-valorisation` | Support de formation à la valorisation d'entreprise (10 modules, quiz, simulateur) | https://eurallia-simulateur-valorisation.netlify.app |
| `quiz-ipag` | Quiz final du cours IPAG Bloc 2 (reprise d'entreprise) : écran élève, écran enseignante `/prof.html`, podium ; fonction Netlify et Netlify Blobs, Base directory = `quiz-ipag` | https://eurallia-quiz-ipag.netlify.app |

Règles :

- Aucun document de dossier client dans ce dépôt.
- La version de référence de chaque page reste dans le Dropbox d'équipe ; ce dépôt n'en garde que la version publiée.
- Les mises à jour sont faites par Claude Code : modification, envoi sur GitHub, publication automatique par Netlify.
